# Marci Metzger Homes

Responsive single-page homepage built with semantic HTML, CSS and lightweight JavaScript. All photography and branding are local supplied assets; Manrope and Inter are locally hosted.

Run `npm install`, then `npm run dev` and visit http://127.0.0.1:4173. `npm run build` creates the static `dist/` folder for any static host. No runtime dependencies or server-side framework are required. The root index.html can also be opened directly.

`npm test` runs responsive and interaction checks using an installed Chrome browser while the local server is running. Screenshots are saved under `qa/`.

See CONTENT-INVENTORY.md for the preservation checklist, source details, search preview values and pending form/reCAPTCHA integrations. Search and contact deliberately display truthful preview feedback. No messages are sent. Google Maps loads only on request.
